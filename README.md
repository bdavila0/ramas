# 📖 Recetario Casero

¡Bienvenido a tu colección de recetas favoritas! Este repositorio contiene recetas de todo tipo organizadas por categoría. Desde desayunos rápidos hasta cenas gourmet, aquí encontrarás inspiración para cada comida del día.

---

## 🍽️ Categorías

- 🥐 **Desayunos** – Recetas fáciles y nutritivas para empezar el día.
- 🥗 **Entradas y Ensaladas** – Opciones ligeras y frescas.
- 🍝 **Platos Principales** – Desde pastas hasta carnes y platos vegetarianos.
- 🍰 **Postres** – Dulces para cada ocasión.
- 🍹 **Bebidas** – Refrescantes, calientes, y cocteles.
